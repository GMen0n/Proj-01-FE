02 — PROBLEM / THE RELIABILITY GAP FP—03 / 14

OWNED ASSETS. UNUSABLE FLEXIBILITY.

✦

A critical data centre already owns flexibility assets — but cannot confidently use them as one combined resource. It has no defensible way to translate live physical conditions into a safe, time-bound flexibility commitment.

VALIDATED
THIS IS A RELIABILITY PROBLEM — NOT A MONITORING PROBLEM.
01

PEAK-SHAVING EATS THE RESERVE

A battery action that pays during a peak erodes state-of-charge headroom and raises tail outage risk — the same battery cannot serve both masters. [R3][R12]

02

COUPLING IS OVER-SIMPLIFIED

Demand-response models flatten the electrical, thermal and computational coupling that actually interacts inside a live facility. [R10]

03

NO WHOLE-FACILITY ENVELOPE

What MW reduction, duration, ramp and recovery can one facility safely promise as a single envelope? Still an open implementation question. [R3][R9][R10]
